# 📦 Control de Pedidos

Aplicación web ligera para la gestión de pedidos a proveedores.

## ✨ Funcionalidades
- Alta, edición y eliminación de pedidos
- Estados visuales (Pendiente / Recibido / Cancelado)
- Persistencia local mediante `localStorage`
- Exportación e importación en JSON
- Exportación a PDF
- Diseño responsive y uso offline

## 🔐 Privacidad
Los datos se almacenan **exclusivamente en el navegador del usuario**.
Los archivos `.json` están excluidos del repositorio mediante `.gitignore`.

## 🛠️ Tecnologías
- HTML5
- CSS3
- JavaScript (Vanilla)
- jsPDF

## 🚀 Uso
Abrir `index.html` en cualquier navegador moderno  
(o usar Live Server en VS Code)
